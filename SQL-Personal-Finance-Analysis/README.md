# SQL Personal Finance Analysis

## Objective
Analyze income, expenses, and savings patterns using SQL.

## Tools Used
- SQL (MySQL)
- GitHub

## Analysis
- Income analysis
- Expense breakdown
- Savings analysis

## Key Insights
- Average income is ₹41,585
- Rent is the highest expense
- Tier 1 cities are most expensive
- Overspending individuals identified

## Dataset Description
The dataset contains information about individuals including:
- Income
- Age
- City Tier
- Occupation
- Various expense categories (Rent, Groceries, Transport, etc.)

## Conclusion
This project highlights how SQL can be used to analyze financial data and identify spending patterns, savings behavior, and financial risks among individuals.
